# Agent Guidelines

## Principles

- Keep items solid and concise (around one line per item) to avoid noise for human maintainers.
- Rules here are preferred guidelines; requirements in `README.md` always take priority.

## Renovate Configuration

- Name the default preset `default.json` so users can use `github>kachick/renovate-config` without specifying a file path.
- Use `.jsonc` for in-repository configurations like `.github/renovate.jsonc`.
